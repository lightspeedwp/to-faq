FAQs for Tour Operator, built on the Yoast FAQ block.

== Description ==

Tour Operator FAQ adds FAQs to Tour Operator sites, built on the Yoast FAQ block:

* A collapsible, accessible accordion for the Yoast FAQ block.
* A repeatable FAQs meta box on posts and the Tour Operator post types, shown with the "TO FAQs" block variation.
* FAQ structured data for Yoast FAQ blocks in templates and template parts.
* An FAQ pattern and template part.

Requires [Tour Operator](https://wordpress.org/plugins/tour-operator/) and [Yoast SEO](https://wordpress.org/plugins/wordpress-seo/).

See the [README](https://github.com/lightspeedwp/to-faq#readme) for the full feature list and filters.
